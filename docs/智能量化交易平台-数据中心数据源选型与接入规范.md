# 智能量化交易平台

## 数据中心数据源选型与接入规范

文档版本： v1.0

文档类型： 架构设计文档附录

编制日期： 2026年9月

## 一、概述

数据中心是整个量化交易平台的基石，其数据质量直接决定了上层策略研发、回测验证和实盘交易的可靠性。本规范旨在明确平台所需各类数据的来源选型、接入方式、存储策略和质量要求，为数据中心模块的开发实施提供依据。

数据中心的”水源”直接决定了整个平台的天花板——垃圾进、垃圾出（Garbage In, Garbage Out）。结合A股市场的实际情况，数据源分为行情数据、财务数据、指数与标的信息、另类数据四大类。

## 二、行情数据源选型

行情数据是量化策略研发和实盘交易最基础的数据支撑，涵盖日线、分钟线、Tick等多个频率级别。

### 2.1 免费/开源数据源

| 数据源 | 覆盖范围 | 频率 | 特点 |
| --- | --- | --- | --- |
| AKShare | A股全市场、期货、期权、基金、债券、宏观经济指标 | 日线/分钟线/Tick（部分） | Python库，完全免费，社区活跃，数据更新及时，是量化个人开发者最常用的起点 |
| Tushare（基础版） | A股全市场、指数、基金、期货 | 日线/分钟线 | 基础接口免费，积分制解锁高级接口（如分钟线需要积分） |
| Baostock | A股全市场（含退市股） | 日线/周线/月线 | 完全免费，无需注册，数据质量较好，特别擅长历史复权数据 |
| Yahoo Finance（yfinance） | 港股、美股、部分A股ETF | 日线/分钟线 | 国际通用，但A股覆盖有限，数据稳定性一般 |

建议： MVP阶段用 AKShare + Baostock 组合即可覆盖日线级别回测需求。AKShare获取实时和最新数据，Baostock补齐历史复权数据。

### 2.2 付费专业数据源

| 数据源 | 覆盖范围 | 特点 | 适用阶段 |
| --- | --- | --- | --- |
| Wind（万得） | A股/港股/美股/期货/期权/债券/基金/宏观，Tick级数据 | 业界标杆，数据质量最高，API完善，但价格昂贵（机构版年费数万起） | 实盘阶段/机构级 |
| 同花顺iFinD | 全市场覆盖 | 性价比优于Wind，API易用，研报数据丰富 | 个人进阶/小团队 |
| 东方财富Choice | 全市场覆盖 | 价格相对便宜，数据全面，适合个人和中小团队 | MVP验证后/小团队 |
| 通联数据（DataYes） | A股为主，另类数据丰富 | 专注量化场景，因子数据开箱即用 | 策略研发阶段 |
| 聚宽（JoinQuant）/ 米筐（RiceQuant） | A股 | 在线回测平台，内置数据+研究环境 | 快速原型验证 |

建议： 策略从回测迁移到模拟盘/实盘时，建议切换到 iFinD 或 Choice 作为主数据源，数据质量和时效性更有保障。Wind适合预算充足的团队。

## 三、财务数据来源

财务数据的核心难点在于披露时间——财报的”截止日期”和”实际披露日期”是两个完全不同的概念，用错就会导致未来函数。

### 3.1 数据源对比

| 数据源 | 覆盖内容 | 说明 |
| --- | --- | --- |
| 巨潮资讯网 | 上市公司年报、季报、公告原文 | 免费，可爬虫获取，但非结构化文本需要清洗 |
| 东方财富网-财务数据 | 资产负债表、利润表、现金流量表、关键财务指标 | 免费API接口，结构化好，更新及时 |
| 同花顺iFinD | 标准化财务数据+调整项+行业对比 | 付费，但财务数据清洗程度高，直接可用 |
| Wind | 最全的财务数据库 | 付费，机构标配 |
| AKShare | 东方财富财务数据接口 | 免费，封装了东方财富的财务数据 |

### 3.2 关键设计要点

所有财务数据必须携带披露日期（Announcement Date）字段，回测时只能使用”截至当日已披露”的财报数据。例如，2025年Q3财报通常在2026年4月披露，那么在2026年1月1日的回测中，最新可用财报应该是2025年Q2的。

## 四、指数成分股与标的信息

指数成分股数据用于构建股票池、进行风格分析和收益归因，其准确性直接影响策略的可信度。

### 4.1 数据源对比

| 数据源 | 覆盖内容 | 说明 |
| --- | --- | --- |
| 中证指数官网 | 沪深300、中证500、中证1000等成分股调整公告 | 免费，但需要手动下载历史调整记录 |
| 东方财富网 | 指数成分股、行业分类、概念板块 | 免费API，可获取历史调仓信息 |
| AKShare | 指数成分股历史变更 | 免费，封装了多个数据源的成分股变更数据 |
| Wind/iFinD | 完整的Point-in-Time成分股历史 | 付费，但PIT数据开箱即用，强烈推荐 |

### 4.2 核心要求

必须维护Point-in-Time（PIT）快照——即”在2025年6月30日这一天，沪深300到底包含哪些股票”。不能用当前的成分股名单去回测历史，否则就是严重的幸存者偏差。

## 五、另类数据来源

另类数据是量化策略获取超额收益的重要来源，但在MVP阶段并非必需，建议放在进化版阶段接入。

### 5.1 另类数据类型

| 数据类型 | 数据来源 | 用途 |
| --- | --- | --- |
| 新闻舆情 | 新浪财经/东方财富新闻API、爬虫抓取财联社电报 | 市场情绪分析、事件驱动策略 |
| 社交媒体情绪 | 东方财富股吧、雪球、微博财经 | 散户情绪指标 |
| 龙虎榜数据 | 东方财富API | 主力资金动向 |
| 北向资金流向 | 东方财富/同花顺API | 外资动向监控 |
| 融资融券数据 | 交易所官网、东方财富 | 杠杆资金情绪 |
| 供应链/产业链数据 | 国家统计局、各行业行业协会 | 宏观经济验证 |
| 卫星/遥感数据 | 商业卫星数据服务商 | 工厂开工率、港口吞吐量等（高端另类数据） |

### 5.2 接入建议

MVP阶段不需要另类数据，先把结构化数据（行情+财务）的管道跑通。另类数据接入放在进化版阶段，因为清洗成本高、信号稳定性需要长期验证。

## 六、数据中心架构建议

结合上述数据源，建议数据中心采用多源冗余 + 分层存储的架构。

### 6.1 架构分层

数据接入层：

- AKShare/Baostock 接入
- iFinD/Choice 接入
- 爬虫/API 接入
- 统一数据清洗管道
数据存储层：

- 时序数据库（InfluxDB/TimescaleDB）：存储行情Tick/分钟线/日线数据（TimescaleDB 是 PostgreSQL 扩展，可与关系型库同实例，避免多一种 SQL 方言）
- 关系型数据库（**PostgreSQL 14+**，已确定）：存储财务数据、股票基本信息、指数成分股 PIT 快照。不用 MySQL——风控层的事务库同样选 PostgreSQL（见风控层契约 §3.6），全平台保持单一方言
- 列式文件（DuckDB + Parquet）：MVP 阶段的研究型存储，零运维、适合回测与因子计算；不承担在线事务
- 对象存储（S3/MinIO）：存储公告原文、研报PDF等非结构化数据
数据服务层：

- 统一DataFeed接口，供策略/回测/实盘共用
- 时间旅行查询（获取某日可见的数据快照）
- 前向填充/后向填充策略
- 复权计算（后复权为主）
- 数据质量监控（缺失值检测、异常值告警）

### 6.2 环境隔离

```
生产环境：实盘数据 + 实盘交易 + 风控执行
模拟环境：实时数据 + 模拟交易 + 策略验证
研究环境：历史数据 + 回测实验 + Agent研发
```

三个环境数据隔离，研究环境的数据污染不能影响生产。研究环境的回测结果不能直接写入生产数据库。策略从研究到模拟到生产，必须经过明确的晋级流程。

## 七、数据规范

为确保数据质量和一致性，需提前定义以下数据规范。

### 7.1 时间戳统一

所有数据统一使用 UTC+8 的交易日时间戳，去掉非交易日。

### 7.2 复权方式统一

回测统一用后复权（避免前复权引入未来信息），实盘用不复权价格。

### 7.3 数据版本管理

每次数据更新打版本号（如 v2026.09.23），回测结果必须绑定数据版本号，确保任何收益都能完整复现。

### 7.4 缺失值处理策略

提前定义好缺失值的填充规则（前向填充 FFill 还是后向填充 BFill），并在接口文档中明确。

### 7.5 数据质量监控

每日数据入库后自动运行完整性检查，包括：

- 停牌股标记
- 涨跌停标记
- 异常成交量告警
- 数据缺失率统计

## 八、MVP阶段数据源务实建议

如果预算有限、追求快速启动，建议的数据源组合如下：

| 数据类型 | 首选方案 | 备选方案 | 成本 |
| --- | --- | --- | --- |
| 行情数据（日线） | AKShare | Baostock | 免费 |
| 行情数据（分钟线） | AKShare（部分免费） | Tushare（积分解锁） | 免费/低门槛 |
| 财务数据 | AKShare（东方财富源） | 东方财富API直调 | 免费 |
| 指数成分股 | AKShare | 中证指数官网手动更新 | 免费 |
| 公告/新闻 | 东方财富API | 爬虫 | 免费 |

总成本：0元。 这套组合足以支撑从策略研发到回测验证的完整链路。等策略跑通、准备上模拟盘/实盘时，再考虑升级到付费数据源提升数据质量和时效性。

## 九、数据源升级路径

随着平台从MVP阶段逐步演进到完善版和进化版，数据源也应相应升级：

| 阶段 | 数据源策略 | 重点投入方向 |
| --- | --- | --- |
| MVP（2-4周） | AKShare + Baostock 免费组合 | 跑通数据管道，验证回测流程 |
| 完善版（+1-2月） | 引入iFinD/Choice付费数据源 | 提升数据质量和时效性，接入分钟线数据 |
| 进化版（+2-4月） | 多源冗余架构，引入另类数据 | 另类数据接入，数据质量监控体系完善 |

## 十、风险与应对

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 免费数据源接口变更或失效 | 数据接入中断 | 多源冗余设计，关键数据源准备备选方案 |
| 付费数据源价格上调 | 成本超预算 | 提前评估ROI，优先投入高价值数据源 |
| 数据质量不达标 | 回测虚高，实盘亏损 | 建立数据质量监控体系，入库前强制校验 |
| 数据合规风险 | 法律风险 | 确保数据源授权合法，遵守数据使用协议 |
| 未来函数/数据泄露 | 回测虚高，实盘亏损 | 严格的数据隔离、PIT数据管理、前视偏差检测 |
