## 全局约定

### 命名规范

- Python类名：PascalCase（如 `StrategyRegistry`）
- Python方法名：snake_case（如 `on_data`）
- 数据类：PascalCase（如 `MarketDataBundle`）
- 枚举值：UPPER_SNAKE_CASE（如 `BUY`、`SELL`）
- 接口名：PascalCase + “Service”/“Manager”后缀

### 异常处理规范

- 所有公共方法必须声明可能抛出的异常
- 使用自定义异常类层次：`BaseStrategyError` → 具体异常子类
- 异常信息必须包含 `strategy_id`、`symbol` 等上下文信息

### 日志规范

- 使用Python标准 `logging` 模块
- 日志级别：DEBUG（详细调试）、INFO（关键流程）、WARNING（可恢复异常）、ERROR（严重错误）、CRITICAL（系统级故障）
- 日志格式：`[%(levelname)s] [%(strategy_id)s] [%(symbol)s] %(message)s`
- 关键日志点：策略启动/停止、信号生成、订单提交、风控拦截、参数变更

#### 1.1.1 Strategy 基类

```python
from abc import ABC, abstractmethod
from typing import Dict, List, Any, Optional
from datetime import datetime

class Strategy(ABC):
    """
    量化策略抽象基类。
    所有业务策略必须继承此基类并实现核心抽象方法。
    """

    @abstractmethod
    def __init__(self, strategy_id: str, config: Dict[str, Any]) -> None:
        """
        策略初始化方法。

        Args:
            strategy_id (str): 策略唯一标识，全局唯一。
            config (Dict[str, Any]): 策略配置参数字典。

        Raises:
            InvalidConfigError: 当配置参数缺失或类型不合法时抛出。
        """
        pass

    @abstractmethod
    def on_start(self) -> None:
        """
        策略启动回调。

        职责: 执行一次性初始化逻辑（如加载因子模型、建立数据源连接）。
        调用时机: 回测引擎启动时、实盘策略激活时。
        注意: 此方法必须是幂等的，可被多次安全调用。
        """
        pass

    @abstractmethod
    def on_data(self, data: MarketDataBundle) -> List[TradingSignal]:
        """
        核心数据处理方法。

        Args:
            data (MarketDataBundle): 市场数据Bundle，包含当前K线/Tick数据。

        Returns:
            List[TradingSignal]: 交易信号列表。返回空列表表示当前无交易意图。

        Raises:
            DataValidationError: 输入数据格式异常或缺失关键字段时抛出。
            StrategyExecutionError: 策略内部逻辑执行异常时抛出。

        注意: 必须是纯函数风格，不修改策略内部可变状态（状态变更通过返回值或框架注入传递）。
        """
        pass

    def on_bar(self, bar: BarData) -> None:
        """
        K线级别回调（可选覆盖）。

        Args:
            bar (BarData): 单根K线数据。

        职责: 每根K线完成时触发，用于K线级别的策略逻辑。
        默认实现: 将BarData转换为MarketDataBundle后调用 on_data。
        适用场景: 需要逐Bar处理的策略（如逐笔委托策略、高频Tick策略）。
        """
        pass

    @abstractmethod
    def on_order(self, order: Order) -> None:
        """
        订单状态更新回调。

        Args:
            order (Order): 订单对象，包含最新的订单状态信息。

        职责: 订单状态变更时触发（已提交、部分成交、完全成交、已撤销、已拒绝）。
        注意: 用于更新策略内部订单跟踪状态，不应在此方法中发起新的下单请求。
        """
        pass

    @abstractmethod
    def on_trade(self, trade: Trade) -> None:
        """
        成交回报回调。

        Args:
            trade (Trade): 成交记录对象。

        职责: 每笔成交发生时触发，用于记录成交明细和实时计算盈亏。
        """
        pass

    @abstractmethod
    def on_stop(self) -> None:
        """
        策略停止回调。

        职责: 执行清理逻辑（如释放资源、保存持久化状态、断开连接）。
        调用时机: 回测引擎停止时、实盘策略停用/退役时。
        """
        pass

    @abstractmethod
    def get_strategy_info(self) -> StrategyInfo:
        """
        返回策略元信息。

        Returns:
            StrategyInfo: 包含策略ID、名称、版本、描述、作者、创建时间等信息的对象。
        """
        pass

    @abstractmethod
    def get_target_positions(self) -> Dict[str, PositionTarget]:
        """
        返回目标仓位快照。

        Returns:
            Dict[str, PositionTarget]: 字典，key为股票代码，value为PositionTarget对象
                                       （含目标数量、目标价格、优先级）。

        职责: 供组合调度层使用，返回的是"持仓意图"而非直接下单指令。
        """
        pass

    @abstractmethod
    def get_strategy_params(self) -> Dict[str, Any]:
        """
        返回当前参数配置。

        Returns:
            Dict[str, Any]: 当前参数配置的深拷贝字典，防止外部意外修改内部状态。
        """
        pass

    @abstractmethod
    def update_params(self, params: Dict[str, Any]) -> bool:
        """
        动态更新策略参数。

        Args:
            params (Dict[str, Any]): 要更新的参数字典。

        Returns:
            bool: 成功返回True，失败返回False。

        Raises:
            InvalidParamError: 参数不合法或超出允许范围时抛出。

        职责: 运行时动态更新策略参数，无需重启策略实例。
        """
        pass

    def on_error(self, error: StrategyError) -> None:
        """
        错误处理回调。

        Args:
            error (StrategyError): 策略执行过程中发生的错误对象。

        职责: 供策略实现自定义错误处理逻辑（如告警、降级、熔断）。
        默认实现: 记录ERROR级别日志。
        """
        pass
```

# 智能量化交易平台 — 核心模块接口契约文档 v1.0（第二部分：回测引擎）

## 模块二：回测引擎（Backtesting Engine）

### 2.1 回测引擎核心类

#### 2.1.1 BacktestEngine 类

回测引擎核心类，负责协调数据源、策略、撮合引擎及绩效分析器，执行完整的回测流程。

- `__init__(self, config: BacktestConfig) -> None`
  - **参数**：`config` (BacktestConfig) — 回测配置对象。
  - **返回值**：无。
  - **职责**：初始化引擎，加载配置，初始化事件引擎、数据源管理器、撮合引擎、绩效分析器。
  - **异常**：`ConfigValidationError` — 当配置验证失败时抛出。
- `add_datafeed(self, symbol: str, datafeed: DataFeed) -> bool`
  - **参数**：`symbol` (str) — 股票代码；`datafeed` (DataFeed) — 数据源实现。
  - **返回值**：`bool` — 注册成功返回 True，失败返回 False。
  - **职责**：为指定股票注册数据源。
  - **异常**：`DataFeedRegistrationError` — 数据源注册失败时抛出。
- `add_strategy(self, strategy: Strategy, capital: float, params: Dict[str, Any]) -> StrategyHandle`
  - **参数**：`strategy` (Strategy) — 策略实例；`capital` (float) — 初始资金；`params` (Dict[str, Any]) — 策略参数。
  - **返回值**：`StrategyHandle` — 策略句柄（含策略ID和初始资金）。
  - **职责**：注册策略到回测引擎，分配初始资金。
  - **异常**：`StrategyRegistrationError` — 策略注册失败时抛出。
- `run(self) -> BacktestResult`
  - **参数**：无。
  - **返回值**：`BacktestResult` — 回测结果对象。

#### 2.2.2 数据源实现示例

CSV数据源实现类示例：

```python
import pandas as pd
from typing import Optional, List
from datetime import datetime

class CsvDataFeed(DataFeed):
    def __init__(self, csv_path: str):
        self.csv_path = csv_path
        self._data: Dict[str, pd.DataFrame] = {}
        self._load_data()

    def _load_data(self):
        df = pd.read_csv(self.csv_path, parse_dates=['datetime'])
        for symbol, group in df.groupby('symbol'):
            self._data[symbol] = group.set_index('datetime')

    def get_bar(self, symbol: str, datetime: datetime) -> Optional[BarData]:
        if symbol not in self._data:
            return None
        df = self._data[symbol]
        if datetime not in df.index:
            return None
        row = df.loc[datetime]
        return BarData(
            symbol=symbol,
            datetime=datetime,
            open=row['open'],
            high=row['high'],
            low=row['low'],
            close=row['close'],
            volume=row['volume']
        )

    def get_bars(self, symbol: str, start: datetime, end: datetime) -> List[BarData]:
        if symbol not in self._data:
            return []
        df = self._data[symbol]
        mask = (df.index >= start) & (df.index <= end)
        filtered = df[mask]
        return [
            BarData(
                symbol=symbol,
                datetime=row.name,
                open=row['open'],
                high=row['high'],
                low=row['low'],
                close=row['close'],
                volume=row['volume']
            )
            for _, row in filtered.iterrows()
        ]

    def get_available_symbols(self) -> List[str]:
        return list(self._data.keys())

    def get_available_dates(self, symbol: str) -> List[datetime]:
        if symbol not in self._data:
            return []
        return self._data[symbol].index.tolist()

    def is_symbol_available(self, symbol: str, datetime: datetime) -> bool:
        bar = self.get_bar(symbol, datetime)
        return bar is not None and bar.volume > 0

    def get_adjustment_factor(self, symbol: str, datetime: datetime) -> float:
        # CSV中需包含adj_factor列
        if symbol not in self._data:
            return 1.0
        df = self._data[symbol]
        if datetime not in df.index or 'adj_factor' not in df.columns:
            return 1.0
        return float(df.loc[datetime, 'adj_factor'])

    def get_dividend(self, symbol: str, datetime: datetime) -> float:
        if symbol not in self._data:
            return 0.0
        df = self._data[symbol]
        if datetime not in df.index or 'dividend' not in df.columns:
            return 0.0
        return float(df.loc[datetime, 'dividend'])

    def get_trading_calendar(self, start: datetime, end: datetime) -> List[datetime]:
        all_dates = set()
        for df in self._data.values():
            mask = (df.index >= start) & (df.index <= end)
            all_dates.update(df[mask].index.tolist())
        return sorted(list(all_dates))

    def get_market_status(self, datetime: datetime) -> MarketStatus:
        for symbol, df in self._data.items():
            if datetime in df.index:
                return MarketStatus.OPEN
        return MarketStatus.CLOSED
```

### 2.9 回测引擎使用示例

以下是一个完整的 Python 使用示例代码，演示了从配置、数据加载、策略注册到执行回测及结果分析的完整流程。假设底层依赖已就绪：

```python
import pandas as pd
from backtest_engine import (
    BacktestConfig,
    CsvDataFeed,
    MA_Cross_Strategy,
    BacktestEngine,
    DataIntegrityChecker,
    ResultSerializer
)

def run_full_backtest():
    # 1. 配置回测参数
    config = BacktestConfig(
        start_date="2023-01-01",
        end_date="2023-12-31",
        initial_capital=1000000,
        commission_rate=0.0003,
        slippage=0.002
    )

    # 2. 加载CSV数据源
    data_feed = CsvDataFeed(
        file_path="./data/historical_prices.csv",
        date_col="trade_date",
        symbol_col="ticker"
    )

    # 3. 创建并注册均线交叉策略
    strategy = MA_Cross_Strategy(
        short_window=10,
        long_window=30
    )

    # 4. 执行回测
    engine = BacktestEngine(config=config, data_feed=data_feed)
    engine.register_strategy(strategy)
    backtest_result = engine.run()

    # 5. 获取和分析结果
    performance = backtest_result.get_performance()
    print(f"总收益率: {performance.total_return:.2%}")
    print(f"最大回撤: {performance.max_drawdown:.2%}")
    print(f"夏普比率: {performance.sharpe_ratio:.2f}")

    # 6. 运行数据完整性验证
    checker = DataIntegrityChecker(data_feed=data_feed, strategy=strategy)
    validation_report = checker.validate()
    if not validation_report.is_valid:
        print("数据验证警告:", validation_report.warnings)

    # 7. 导出回测报告
    serializer = ResultSerializer(backtest_result)
    serializer.export_to_csv("./output/backtest_report.csv")
    serializer.export_summary("./output/backtest_summary.json")

if __name__ == "__main__":
    run_full_backtest()
```

### F. I4 绩效看板的读数口径登记（2026-09-25 追加）

本节由实现迭代 I4 追加，登记**绩效看板**（`quanauto/dashboard.py`，以及 `quanauto/cli.py` 的 `dashboard` 子命令）的读数口径。**本节不修改上文任何段落**（本文档由 .docx 派生，只允许追加）。一句话判决：**看板是纯读数组件 —— 屏幕上出现的每一个数，都是 §2.5 的 `PerformanceAnalyzer` 在本次回测里算出来的数，看板一个都不重算。**

**F1. 「只读数不算数」是本轮的第一条口径。** 看板能做的只有三件事：读报告 → 按固定清单摆位置 → 做量纲换算（比例 → 百分号）与定点小数。**不许出现任何统计计算** —— 均线、方差、分位数、回撤重算、收益率重算都属于 §2.5 的地盘。机器判据在门禁 `dashboard-consistency` 的 C6：看板模块里一旦出现 `performance` / `statistics` / `numpy` / `pandas` / `scipy` 任一 import，或出现 16 个统计函数名之一，即 FAIL。**理由**：若 §2.5 与看板各算一套指标，同一种数就有了两个来源，两边对不上时谁对无法判定 —— 那正是本轮 DoD 要防的事。

**F2. 字段清单（14 项，与 §2.5 的 `PerformanceMetrics` 双向相等）。** 看板展示的指标就是 `PerformanceMetrics` 字段的**全集**：多一个 = 看板自造指标（F1 禁止），少一个 = 报告里有读数而看板看不见。双向相等由门禁 `dashboard-consistency` 的 C2 守着（拿 `quanauto/models.py` 里那**真 dataclass 的字段表**去比看板常量表的两边，不是比名字出现过）。

**量纲是显示层的事，不是报告的事。** 报告里 `total_return` / `max_drawdown` / `win_rate` 存的都是**比例**（`0.1234` 意为 12.34%），看板负责乘 100 再加 `%`；`final_equity` / `total_commission` 是金额，原样输出。计数类指标若报告里给了非整数（`total_trades = 2.5`），看板**报错而不是取整** —— 显示时静默截断，会让「报告与看板对不上」这件事看起来像对上了。

**F3. 回撤是正数百分比。** §2.5 的 `drawdown_series` 定义是 `(峰值 - 当前值) / 峰值`，因此**回撤取正号**（回撤 12.34% 存作 `0.1234`，不是 `-0.1234`）；`max_drawdown = max(drawdown_series)`，`final_equity = equity_curve[-1]`。看板两处（指标表里的最大回撤、资金曲线下方的曲线统计）显示的都是这个正数百分比，**符号不做翻转**。资金曲线本身按 `equity_curve` 原样画 —— 它是净值曲线，不是收益率曲线。

**F4. 取不到就报错，不退回 0。** 报告缺 `performance` 段、缺某个字段、值不是有限实数（含 `NaN`、`inf`，以及 `true` / `false` —— `bool` 是 `int` 的子类，退化成 1 非常隐蔽）、枚举值不是枚举成员、时间戳不是 ISO 8601：一律抛**看板异常**（`quanauto/errors.py`，公开错误码 `DASHBOARD001`，继承本项目的根异常）并**点名是哪个字段**。结构性缺失（`trades` / `orders` 段不存在）是唯一例外：那两处显示 `-` 而不是 `0` —— 「没有这一段」与「这一段是空的」是两件事，用 0 表达会让人以为确实一笔都没成交。
