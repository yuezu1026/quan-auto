HIGH-FIDELITY SPEC · 参考稿视觉语言移植

把「已经想清楚的东西」画成能看的界面，
并且不假装它已经能跑。

这份稿子的输入有两个：docs/low fidelity/ 里那份已经把信息架构、八帧、状态矩阵、追溯表想清楚的低保真， 以及仓库里**已经交付的真实语义**（F5 绩效看板的字段与展示文本、F6 的六条风控规则与默认阈值、F4 的报告夹具）。 视觉语言参考 fst-3end-ui-design.html。输出是这一份带 token、带组件、带八帧的界面稿 —— 它换的是「皮肤」，不换低保真已经定下的结构与判断。

① 只有 F5 是已交付 其余七帧每一帧都带「提案」章、整帧点划线外框。低保真图例里的「实线=已交付 / 点划线=提案」在彩色稿里必须活下来。
② 数字要么有出处，要么是 [占位] 高保真不等于编数。仓库里有真值的写真值并注明出处；没有的保留占位符，且占位符看起来就像占位符。
③ 控件不可按，并且写明为什么 除主题切换与锚点跳转，本稿所有按钮 disabled，各自 title 里写清缺哪一项能力。
④ 颜色不承担唯一语义 状态一律「文字 + 形状 + 颜色」三重编码；把颜色去掉之后，这张稿子仍然读得出来。

01.2 · 本稿新增的 3 个 token（**不是**从参考稿抄来的）

参考稿是「设备互传」，没有行情语义。本稿要画涨跌与图表占位，所以新增三个变量。 它们不是「参考稿里有」的东西，是这一款的设计决策，逐条给理由。

Token值（浅 / 深）为什么这么定
--up#B3372F / #F0918B 涨。取红是因为 A 股口径红涨绿跌；但把明度压到比 --err 更沉， 并且规定它只出现在行情/成交字段上，绝不用来表达「出错了」。
--down#0E7A5C / #5FD0AC 跌。同理与 --ok 同色系但更沉。状态色与涨跌色是两套语义，禁止互换 —— 这也是 F5 那一屏不打算给绩效数字上色的原因（见 04·F5 注解 6）。
--hatch45° 斜线，surface2/3 交替 图表占位。直接继承低保真图例里的「斜线阴影块 = 图表占位」，让缺口在彩色稿里仍然一眼可辨， 不会因为换了皮肤就被读成「已经画好了」。

01.3 · 借来的语言 vs 本稿的裁决（六条，逐条可核）

#参考稿的做法本稿理由
1设备框固定高度（.desk{height:640px}）+ 内部滚动 改：内容自然流动，不设固定高度 那是「三端预览器」，每屏只展示一部分；本稿八帧每帧都有十几行表格，固定高度会把内容藏进滚动条里，读者核对不到。
2背景三层 radial-gradient 品牌淡色晕染沿用同一族，无冲突。
3按钮可点、点了有 toast 改：一律 disabled，title 写明缺什么 参考稿是「三端都能跑」的成品稿；本稿只有 F5 有实现。画一个能按但没有实现的开关，是这份稿子最容易犯的错。
4用 绿=成功 / 红=失败 表达状态 加约束：红绿只表达状态，不表达涨跌 量化界面里「红」同时是「涨」和「错」，分不清就会出事。靠新增 --up/--down + 规定使用域来分开。
5顶栏只有一个主题切换 加：环境徽标 + Kill Switch 常驻 低保真已经把「环境可见性」与「Kill Switch 每屏可达」定成硬约束（F1 注解 1、F6 注解 3），这两样必须在壳里。
6整页无「提案 / 已交付」标记 加：帧级状态章 + 点划线外框 参考稿的所有页面都真的存在；本稿八帧里七帧不存在。不加这层标记，这份稿子就成了一句假话。
02

组件条（带用法约束，不是样式清单）

参考稿的 §01 是「token + 组件条」。本稿沿用它的形态，但每一条都补一句域内约束—— 量化界面里「点错了」比「看不懂」贵得多，所以每个组件都要写清它不许用在什么地方。

02.1 · 动作（全部 disabled —— 本稿唯一可用的动作是主题切换与锚点）

无可实现

约束：危险动作（触发熔断 / 清仓 / 删除规则）必须反白或危险色 + 二次确认， 且不可以是列表行尾的默认焦点按钮。disabled 在这里不是「还没做完」的偷懒， 而是把「本稿没有实现」写成可核对的事实 —— 悬停任一按钮，title 会说出缺哪一项能力。

通过 缩减 拒绝 提案 待人工 未触发

约束：风控的三类判定 PASS / REDUCE / REJECT（HALT 只在熔断里出现）是三个不同的词， 「缩减」既不是通过也不是拒绝 —— 界面上不许出现「通过（已缩减）」这种合并写法。 徽章一律带文字，不出现纯图标状态。

正常 进行中 待人工 熔断 未启用

约束：圆点只是强化，右侧永远有文字。进度条的百分比取自服务端的「已处理 n / N」， 页面不自己算比例。

规则启用 全市场池 沪深300池 + 新建池

约束：比例输入框只收 (0,1] 的小数，不收 20%。 右侧那格是故意画成「填错了」的样例 —— 一个既能读成 2 成又能读成 20 倍的输入框， 迟早会有人填错。

02.2 · 流程链与占位块

日频交易循环
选源与区间→ 取数→ 帧校验→ 盖 source / data_version→ 落库→ 写批次留痕
策略进化循环
失效检测→ 假设生成→ 回测验证→ 晋级推荐（人工）

约束：链上的节点有四种状态：已完成（绿淡底）/ 进行中（主色描边 + 焦点环）/ 待办（中性）/ 端点（反白）。 反白只留给「人工动作」，一屏里最多一处 —— 反白用多了就不叫强调了。

斜线阴影 = 图表占位
本稿的缺口用这个画法表达
点划线框 = 提案
整帧外框是虚线，说明这一帧没有实现
缺口块：写「要什么、为什么现在给不了、该修哪一侧」，而不是写「待完善」。

① 环境徽标（三态：研究 / 生产 / 跨环境） 常驻在每一帧的顶栏右侧。它是「我现在看的这一屏代表哪个环境」的唯一答案。
② Kill Switch（每屏可达，反白） 反白是「这是危险动作」的形状语言。它一经触发，所有下单路径都停 —— Agent 与策略都绕不过。
③ 人工决策区（唯一写操作区） 每个需要人拍板的东西都聚到 F1 的一个区里，不让它散落成「某个页面角落里的一个按钮」。
  1. 为什么要有外壳帧：八帧共用同一套导航与顶栏，单独看某一帧会以为「环境徽标是那一屏自己加的」。把它抽出来画一次，五次重复才变成一条约束。
  2. 导航里写了帧号（F1…F8）是这份稿子的需要，不是产品的需要 —— 真实界面上那一格应当放数量角标（待采集批次数 / 待人工决策数）。本稿保留帧号，是为了让读者能把图和低保真的八帧对上号。
  3. 绩效区在导航里只有一项（F5）。需求里的绩效模块确实只有这一屏可交付，其余（归因、报表导出）在 §06 的缺口清单里，不在这里画假入口。
  4. 断点：1180px 以上是设计宽度；980px 以下侧栏塌到顶部；700px 以下所有多列网格变单列。本稿在 700px 处只保证「不溢出」，不保证好用 —— 桌面端产品，移动端只是兜底。
  5. 这一帧也是提案，不是已交付。已交付的 platform/web/src/App.jsx 只有一个 <header> 加一个报告选择工具条，没有侧栏、没有常驻顶栏、没有环境徽标位 ⇒ 图里这一整套外壳目前只存在于本稿与低保真里。它标成 提案（点划线外框），与 F1~F4 / F6~F8 同一待遇。

每一步都产出一份可审计的中间物。界面的任务是让人在两三分钟内判断「要不要点那个晋级的按钮」。 每一步都能停，停下来的状态是「待人工」而不是「失败」 —— 把等待人决策画成红色失败，会训练用户忽略红灯。

没有画进来的几件事（它们的缺失是刻意的）

收益归因的三张表（资产配置 / 风格 / 策略贡献）： 它们应该是 F5 的一级标签页，而不是新的一屏。本稿没画，是因为 F5 已交付而现有页面没有这一层 —— 属于「已交付屏的待扩展项」。
执行层的其余结构：订单拆分、智能路由、持仓同步、模拟盘 / 实盘切换。 F8 只画了「成交回报 + 滑点」这一面，因为那一面是成本分析的输入；其余几面是执行引擎自己的事。
组合调度的再平衡触发：本稿只画了手动覆盖，没有画「定期 / 阈值 / 事件」这三类自动触发在界面上怎么呈现。 少了它，「多久动一次仓」这个问题在界面上没有落点。
以「模拟环境」为主语的那一屏：环境徽标有三种取值，本稿用到研究（多数帧）、生产（F6）与跨环境总览（F1）。 模拟盘只出现在 F7 的生命周期阶段里，没有单独一屏。
多用户 / 权限 / 计费：PRD 明确第一版完全自用、不做这些。 所以本稿里没有登录页、没有角色管理。
视觉与品牌：低保真刻意不涉及 —— 本稿就是来补这一格的。 但补的方式是「画出来给人看」，不是「加一条判据」。

07

本稿不主张什么

逐条写明，避免被当成证据引用。

  • 它不是界面规格、不是契约、不是门禁，也不构成任何判据。没有任何门禁读本文件 —— 所以它没有牙。
  • 它不解除「布局 / 视觉仍然零覆盖」这一条。画了高保真等于有了一张更细的纸，不等于有人守着布局。那一格的现状见 docs/智能量化交易平台.md 附录C §C.14。
  • 它不主张除 F5 之外的任何一帧已经有实现。F5 那一帧的信息来自真实实现，但它的皮肤是本稿换的 —— 所以也不主张 F5 与已交付页面逐像素一致。
  • 它不主张里面的 [方括号] 占位是待办清单，也不主张方括号外的数字全部来自产品接口 —— 每个数字的出处写在它旁边（帧抬头 数值源 + 帧内 hint）。
  • 它不是平台层开工的信号：平台层那一层有它自己的四条门禁与边界裁决，本稿不改动其中任何一条。
  • 它不主张自己「受控于」任何东西。换肤这件事本身没有判据，这一点在本稿里是明说的，不是隐瞒的。
