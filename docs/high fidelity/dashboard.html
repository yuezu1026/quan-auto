照抄出来的两处「不该修」的现象

  • 抬头写「成交 3 笔」、指标表里「成交笔数」是 1 —— 两个数都来自同一份报告 （counts.trades = 3 = 流水条数；performance.total_trades = 1 = 指标口径）。 页面照抄、不解释。设计稿若把它改成一致，那不是修 bug，是发明一个上游没有的事实。
  • 文案里的单个空格（如 ； 本页、是 同一份、 、 platform-web-parity）：来自 JSX 里显式的 {" "} 与换行折叠。 真页面就是这样；改掉它，这一稿就不再是照抄。这些空格现在由生成器现折叠， 不再手抄（手抄版曾在 输入是一份 / 夹具）覆盖 两处错了位置）。

同一页还有两个真实态（本稿没有画，见 README 的说明）

  • 读取中：<span class="busy">读取中…</span>，选择框在报告列表为空时 disabled；此时抬头 / 曲线 / 指标都不渲染（不会被旧数字垫着）。
  • 出错：<p class="error">…</p>，且渲染被 view && !error 挡着 ⇒ 出错时不显示旧数据。

还有一件事要说清楚：本稿 0 个 <script> ⇒ 上面那个「报告」选择框是死的（切了不会换报告，也不会去请求 REST）。 它被照抄下来是为了核对样式与文案，不是摆一个假开关； 要看真能切的那种，用 docs/low fidelity/prototype.html。
